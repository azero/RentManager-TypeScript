# Changelog

## 0.1.0

- Initial TypeScript port of the Python and PHP Rent Manager WAPI12 SDKs.
- Complete generated catalog with 338 resource namespaces, 361 models, and
  1,579 endpoint-registry entries.
- Authentication, retries, automatic reauthentication, RQL, pagination,
  multipart upload, binary download, token stores, typed errors, and generic
  endpoint access.
- Email lookup and full service-ticket detail/export workflows.
