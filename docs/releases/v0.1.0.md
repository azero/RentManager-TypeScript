# @azero/rentmanager-api 0.1.0

Initial public release of the TypeScript SDK for Rent Manager WAPI12, ported
from the existing Python and PHP SDKs.

## Highlights

- Complete generated catalog: 338 resource namespaces, 361 models, and 1,579
  endpoint-registry entries.
- Async authentication, retries, automatic reauthentication, RQL,
  pagination, multipart uploads, binary downloads, token stores, typed
  errors, and generic endpoint access.
- Email lookup and full service-ticket detail/export workflows.
- ESM and CommonJS builds with declarations for Node.js 18 and newer.
- Catalog parity checks tied to the documented Python and PHP source
  baselines.

## Validation

- 32 automated tests across five test files.
- 84.57% statement/line coverage and 78.65% branch coverage.
- ESM and CommonJS package smoke tests on Node.js 18.
- Zero known npm audit vulnerabilities at release time.

The attached `azero-rentmanager-api-0.1.0.tgz` is the installable npm package
artifact. npm registry publication is intentionally separate from this GitHub
release.
